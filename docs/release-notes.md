# Build 8 发布说明草稿

状态：本地待审阅，尚未发布。

## Celeste iPadOS · Build 8

基于 Steam macOS Celeste **1.4.0.0** 的非官方 iOS / iPadOS 原生移植。

- ARM64 AOT + LLVM，FNA3D Metal 后端，原生 FMOD 音频。
- 恢复原版 320×180、16:9 等比例显示，iPad 保留上下黑边。
- 完全移除实验性扩展视野和对应设置开关。
- 保留手柄按键重复触发修复。
- 保留首屏免费声明、简繁英本地化，以及系统设置中的声明、Metal 性能面板和诊断日志开关。
- 当前为原版 60 帧循环，没有 120 帧模式和游戏内虚拟触屏按键。

## 安装与更新

构建工具生成未签名 IPA，使用自己的签名方式安装。更新前备份「文件」App 内蔚蓝的 `Celeste` 文件夹，并保持相同 Bundle ID 和兼容签名身份进行覆盖安装。

仓库只提供构建工具。游戏资源、SDK、签名材料和完整 IPA 不在 Git 源码中。

## 验证范围

已通过本仓库的 `deps → prepare → native` 完整流程生成 Release / ARM64 AOT IPA，原生库从固定版本的官方源码重新编译。复建时因 GitHub 连接故障使用了此前获取的官方源码缓存。

与原 Build 8 对照，919 个游戏 C# 文件及 1216 个游戏资源文件完全一致；首屏图片、设置开关和应用标识一致。程序二进制、应用图标与启动画面的打包结果有所不同。

此前版本已在 M1 iPad / iPadOS 26.6.2 上检查启动、关卡画面、Xbox Series X 手柄与原生 Metal HUD。此次复建包尚未安装进行实机验证。
